# iOS 精选集导航验收

## 最终行为

- 精选集首页展示服务器根目录、数量及本地“暂未开放”占位，没有全部照片、精选或管理入口。
- 文件夹照片页复用主图库，标题为当前文件夹名称；同一标题行提供返回和子文件夹图标。精选集隐藏日期，主图库及全屏照片标题显示纯日期。
- 顶部使用半透明磨砂材质和独立安全区域占位，照片背景色延伸到导航背后。
- 子文件夹菜单为全宽、直角、半透明覆盖层；展开不改变照片视口尺寸和位置。
- 目录加载独立于照片分页；切换目录清除搜索和多选，旧响应不能覆盖新范围。本地占位不申请权限。

## 验证

- iPhone 17 Pro / iOS 26.4 模拟器 Debug arm64 构建、安装和启动通过；Xcode 27 SDK 使用 `ARCHS=arm64 ONLY_ACTIVE_ARCH=YES`。
- 连接真实 NAS 只读核对首页、photo → 未处理 → 2020 → Fairbanks、返回导航、目录层级恢复、多选清除。
- 展开和收起菜单后照片位置一致；顶部与菜单磨砂效果、全宽直角及精选集无日期已查看模拟器截图。
- 共享 Swift 测试 22 项、3 个 suite 通过；后续仅 UI 调整使用模拟器构建验证。
- 本轮未修改服务器照片，未覆盖断网故障注入、横屏和真机触感。
