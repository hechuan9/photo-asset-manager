# NAS 统一路径与目录关联恢复

此前 catalog_assets 约 117,290 个，但 catalog_paths 仅 11,930 条。历史 Mac 种子迁移只迁入资产和 placement，placement 不含文件路径；目录筛选依赖 catalog_paths，导致真实文件夹显示为空。

本轮将原片同路径只读挂入容器，路径身份统一为 NAS `/volume2/...`。追踪根 `/originals` 迁为 `/volume2`；catalog_paths、扫描增量 files、folders 和任务 current_path 同步迁移。路径筛选不再混用容器别名或 Mac `/Volumes`。

目录导航为每个返回目录探测可见直接子目录，找到首个即停止，返回真实 hasChildren 布尔值。文件、隐藏目录、系统目录、符号链接不算可展开子目录。

旧 Mac 数据库仅用于一次性恢复历史路径关联：导出 142,008 条 NAS 原片记录，在 NAS 验证普通文件、无符号链接、大小一致及已有 catalog_assets/catalog_files 关联一致。dry-run 可恢复 131,882 条，已有 10,126 条，无缺失或冲突；未重新读取全量内容哈希，不新增已校验扫描状态或在线 holder。

本地 Rust 39 项通过、1 项 Linux 媒体运行时测试按标记跳过；迁移脚本临时数据库测试覆盖 dry-run、备份、事务冲突回滚、幂等、原片不变。

部署完成：`keeps-server:nas-root-20260926`，镜像 `6671028022d0`。备份位于 `/volume2/myphoto/keeps/backups/nas-path-migration/20260926T214024.271991Z`，两个 SQLite 完整性检查通过。正式迁移 11,984 条现有路径、恢复 131,882 条历史关联，最终 143,866 条；无 `/originals` 或 `/Volumes` 遗留 catalog_paths。

现场 API 检查：photo 87,717 个资产，photo/照片 29,560 个，photo/未处理 42,056 个，和川专属 29,140 个。四个原片挂载均同路径且只读，后台任务已从 `/volume2` 恢复运行。详见 迁移结果：`nas-paths-migration-20260926.json`（本地现场记录，未入库） 与 现场接口验证：`nas-paths-live-20260926.json`（本地现场记录，未入库）。
