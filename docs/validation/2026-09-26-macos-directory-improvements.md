# Mac 目录与图库改进验证

## 功能

- 目录与图库使用原生可拖动分割，目录宽度范围 200–480 pt。
- 目录滚动条使用自动隐藏的浮层样式。
- 底部加载区在请求期间出现时，请求结束后继续处理分页需求；失败停止自动重试。
- 隐藏目录标记持久化 NAS，父目录设置向后代继承。全库、精选、回收站、搜索和上级目录浏览过滤隐藏照片；明确进入隐藏根或后代可查看，独立隐藏的更深后代仍需进入。Mac 系统“显示”菜单可关闭过滤。
- 隐藏是浏览过滤，不是原片加密或密码锁；没有删除、移动或覆盖原片。

## 现场界面抽样

- 旧安装仍使用“加载更多”按钮；运行工作区新构建确认该按钮已移除。
- 原生分割条拖动后宽度从 480 pt 变为 300 pt。
- NAS 升级后 Mac 来源正常加载；目录右键显示“设为隐藏目录”，右键本身保持当前图库范围。目录滚动条在静止且无需滚动时不可见。
- 最终构建系统“显示”菜单包含“过滤隐藏目录内容”，无重复菜单。
- 读取真实图库总数 117,344，自动加载至 300 张，继续滚动后达到 500 张。
- ad hoc 包首次请求曾返回 macOS Local network prohibited；手动重试后真实图库请求成功。此结果不代替 TestFlight 沙盒安装验收。
