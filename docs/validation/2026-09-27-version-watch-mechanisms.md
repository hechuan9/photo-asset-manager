# 版本与文件监听机制验证

范围：本地代码和隔离 Linux 容器。未部署 NAS，未迁移或整理生产数据库，未访问或修改用户照片。

## 实现边界

- schema 3 新增版本证据、默认版本和修订信息；迁移测试证明旧资产不合并、不拆分、不回填。
- 文件内容哈希／精确 JPEG 编码图像证据可自动归组；拍摄元数据只产生候选。RAW 与成片、裁剪调色的视觉相似确认仍待样本校准，未加入任意阈值自动合并。
- 版本列表和指定默认接口、默认稳定选择、缺失重选、过时预览提交拒绝。
- 文件事件按目录持久化、防抖、处理中重排、优先处理、重启恢复、有限重试；周期核对包含 XMP 签名。
- macOS/iOS 前台 revision 轮询、按变化刷新、详情版本列表和默认选择。

## 验证

- macOS 上 Rust：45 个库测试、9 个 HTTP 测试通过；Linux 媒体测试在本机跳过。
- Clippy：所有 target 通过，warnings 作为错误。
- Linux Docker：46 个库测试通过（包含原生文件监听）；真实媒体测试另行通过，覆盖 JPEG/PNG/TIFF/HEIC 解码预览和原片哈希不变。
- shared Swift：17 项测试通过；macOS：24 项测试通过。
- iOS Simulator Debug 无签名构建通过；版本刷新依赖 updatedAt 的最后改动另经 macOS 编译验证。
- `server/tests/mechanisms_smoke.py` 通过：关闭周期扫描触发机会（间隔 3600 秒）后，由 Linux volume 文件事件完成新增、精确版本归组、同秒不同画面不合并、默认选择、移动、删除后的可用版本选择和预览重建、服务重启、停机期间仅 XMP 变化的补漏。服务以只读方式挂载临时原片，写入/移动/删除由独立测试容器模拟外部用户操作；保留的原片哈希不变，原片目录没有生成预览。

- 原有 `docker_smoke.py` 隔离回归通过：保留历史 ledger、鉴权与预览签名、增量幂等、停止追踪、坏文件有限重试、SIGKILL 后任务恢复和全部原片哈希核对。脚本已适配 schema 3 与目录级任务；损坏 JPEG 在身份提取阶段报错，不进入照片资产。
- 最后的默认版本 API 前置检查经 HTTP 回归和 Clippy 验证：目录已停止追踪时返回 409，保留原默认和修订号。

## 现场限制

Docker Desktop 宿主共享目录的写入未在本次测试中传递实时事件；测试改用原生 Linux volume 验证 NAS 所需的内核事件机制。周期核对仍是事件丢失后的补漏路径。真实 Synology Docker 挂载、SMB 写入、inotify 限额、挂载异常及客户端实际安装的端到端验收尚未执行。

生产升级须停服备份两个 SQLite，再显式迁移 catalog schema 3；此报告不是生产部署或历史照片整理完成证明。
