# iOS 全屏图库与时间轴

版本：0.3.0 (6)。

## 变更

- 最新照片在底部，进入时定位最新，向顶部续载更早页；全屏浏览器遵循相同时间顺序。
- 原比例照片铺到状态栏和底部控件之后；顶部标题、日期、选项与选择按钮，以及底部图库、精选集、搜索按钮浮动显示。
- 精选集接入现有留用与回收站；独立搜索面板查询文件名或相机。
- 多选可留用、移入回收站或恢复；全选范围明确为已加载照片；回收站操作需要确认，不操作原片。
- 浏览旧内容时暂停自动刷新；刷新重新读取已加载窗口，保留分页范围。少量搜索结果靠上显示。

## 验证

- iPhone 17 Pro / iOS 26.4 模拟器正常签名构建通过，Release archive 通过。
- 真实 HTTPS 图库原比例网格铺满屏幕，默认位于最新一端。
- 连续向下轻扫（浏览更早照片）跨页后出现更早文件；方向与顶部续载正确。
- 进入选择模式，点击照片后显示“已选 1 张”，取消恢复浏览；未对生产照片执行批量修改。
- 精选集打开留用查询；搜索输入、提交与退出流程正常。

真机触感、横屏及生产照片批量修改尚未验收。共享布局算法未修改。
