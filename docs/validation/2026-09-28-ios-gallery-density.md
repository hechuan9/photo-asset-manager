# iOS 图库面积与缩放

目标版本：0.3.0（7）。

- 大图以每行三张 2:3 竖图为面积基准；同一行等面积，支持一横两竖，纯横图通常两张。
- 中图以五张竖图为基准；密集档每行九张方形裁切缩略图。全屏查看保留完整比例。
- 双指收拢/展开按大图、中图、密集切换一档；菜单提供相同选项，设置持久化。
- 可见行才创建图片视图；首批与分页 200 张，保证密集档覆盖手机视口。

验证：

- iPhone 17 Pro / iOS 26.4 模拟器构建通过；真实资料库验证大图、中图及密集档，菜单切换成功，密集档九列铺满视口。
