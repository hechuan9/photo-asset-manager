# NAS 自动缩略图流水线实施计划

状态：用户已授权开始并监控；沿用当前工作区，不回退此前修改，不提交无关改动。

目标：NAS 独立完成入库后缓存生成及历史重建；外部只读监控。
设计：[已批准方案](../thumbnail-rebuild-design.md)。

## 接口和责任

- server/**：NAS 实体表迁移、持久缓存状态、单worker限额调度、媒体输出和读取API。
- shared/**、ios/**、macos/**：thumbnail/standard角色、缓存隔离与迁移、查看器和低优先级预取。
- deploy/**、scripts中本次部署工具、docs/**：根代理负责样本、备份、部署、线上核验和监控。
- 资产新增 thumbnail 和 standard 可选描述符，均为 downloadURL/width/height/version；旧 preview 在客户端发布完成前保留。
- GET /derivatives/{asset}?role=thumbnail|standard|preview 刷新签名；GET /libraries/{library}/cache-status 查看统计。

## 执行步骤

- [x] NAS基线：运行镜像、原片只读挂载、CPU/内存/空间、DB版本及任务；源文件抽样比较尺寸和耗时。
- [x] 服务端迁移：独立照片/视频/目录实体，保留业务身份；缓存源版本/规格/状态/错误/重试持久化。
- [x] 服务端流水线：每轮20、全局并发1、轮间60秒、编码线程1；新增和重建共享；文件验证发布后登记；失败/重启恢复。
- [x] 客户端：网格小图、展开标准JPEG/HEIF，角色缓存隔离，旧缓存一次性迁移，恢复预取；保持既有列表刷新交互。
- [x] 必要验证：Rust/Swift测试、原片不变、限额、源版本竞争、丢失修复、重试、解码、流式下载与鉴权。
- [x] NAS隔离测试：真实编解码、样本新图尺寸/大小、重启恢复、资源限额；失败则先修复。
- [x] 部署：保留旧镜像，停服一致备份双库和配置，迁移比对业务表，恢复服务，检查HTTPS和原片挂载。
- [x] 启动低负载全库处理；隔离库验证完整批次和休息窗口，生产观测推进并继续记录首个完整批次；旧预览切换后延迟清理。
- [x] 发布客户端可用版本并核验；开启心跳监控，只有完成、失败、停滞、资源问题或需要用户操作才通知。

## 验证关注

RAW-only与缺失源不能伪报完成；超大图片的子进程内存和时间限制；新增与历史任务不能各起并发；数据库就绪与实际文件一致；旧客户端仍依赖preview时不得清理其当前引用。
